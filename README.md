# Lumina - Booking Website (Beginner Version)

A simple, clean booking website built with basic HTML, CSS, and JavaScript.

## 📁 Files

- **index.html** - Simple HTML structure
- **style.css** - Basic CSS styling  
- **script.js** - Simple JavaScript code

## ✨ Features

1. **Sticky Header** - Header stays at top when scrolling
2. **Mobile Menu** - Burger menu for mobile screens
3. **Slider** - Room cards that slide left/right
4. **Modal/Form** - Booking form with email validation
5. **Go Top Button** - Appears after scrolling down
6. **Cookie Bar** - Shows cookie notification
7. **Countdown Timer** - 10-minute timer in modal
8. **Simple Animations** - Cards fade in on scroll
9. **Responsive Design** - Works on all devices

## 🎨 Styling

- Simple color scheme with primary blue (#4a5eff)
- Clean, readable fonts
- Smooth transitions (0.3s)
- Mobile-first responsive design

## 🚀 How to Use

1. Open `index.html` in your browser
2. Click "Search Rooms" or "Get Started" to open booking form
3. Try burger menu on mobile (resize window)
4. Theme button stays in light mode only
5. Scroll down to see animations

## 💻 Code Structure

### HTML
- Simple semantic structure
- No complex nesting
- Easy to understand

### CSS
- Basic selectors (not BEM)
- Simple animations
- Media queries for mobile

### JavaScript
- Simple event listeners
- Basic validation
- No complex functions
- Easy to follow logic

## 📱 Responsive Breakpoints

- **Desktop**: Full layout
- **Tablet (768px)**: Burger menu appears
- **Mobile (480px)**: Single column layout

This is perfect for beginners to learn:
